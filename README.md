# DMS Collections — animated prototype (Next.js + TypeScript)
`npm install && npm run dev`. The app renders `public/prototype/index.html` full-screen.
Source of the prototype: `prototype-src/` (plain JS; `python3 prototype-src/build.py` rebuilds the single HTML file).
Flow: logo intro -> login -> customer search -> LAN picker -> overview / timeline / rule configuration. Themes: Pop, Midnight, Soda, Neon.
